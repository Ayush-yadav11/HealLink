From a symptom to a doctor in 3 screens

  1. Ask a health question, typed or spoken

    Type in the box or press the microphone: the browser’s speech recognition writes English as you talk.

  2. Read the health assessment

    Gemini 2.0 Flash returns the likely issue, an urgency of low, moderate or high, and advice. One tap shows it in Hindi.

  3. Find a doctor in the app

    Search the directory by name or specialty, or show only verified doctors, and open a doctor’s hours.

Built with React 18, Vite and Gemini 2.0

  • Interface React with Material UI, Framer Motion and a light and dark theme
  • Answers Gemini 2.0 Flash through Google’s generative AI SDK
  • Hindi Google Cloud Translation, version 2
  • Voice the browser’s Web Speech API

Does the assistant diagnose illness?

No. It gives general guidance and an urgency level; see a doctor for anything worrying.

Are the doctors in the app real?

Not yet: the eight doctors are not real practices, and booking only shows a confirmation.

Does the health assistant work offline?

No. Each answer comes from Gemini, and the Hindi from Google Cloud Translation, so both need a connection.

Which languages does the app speak?

Answers come in English or Hindi. Voice input listens in English for now.

What does the app need to run?

A Gemini key and a Google Cloud Translation key in .env, then npm run dev.

Why was the health assistant built?

For the GDG Solution Challenge 2025: health guidance for people far from a clinic.

Run HeaLink AI on your machine

Add your Gemini and Translation keys, then npm run dev.
